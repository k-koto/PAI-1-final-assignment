# ヨットのバランスを取る Physical AI

470級ヨットを模した簡易モデルの上に SO-101 ロボットアームを載せ、風で傾く船を**ハイクアウト**（風上側へ体重を乗り出す技術）で水平に保つよう、強化学習で制御を学習させたプロジェクトです。

- シミュレータ: MuJoCo
- ロボット: SO-101（[MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie/tree/main/robotstudio_so101) のモデル）
- AI: Stable-Baselines3 の PPO（CPUのみ・約4分で学習）
- デモ動画: （YouTube URL を記載）

## 仕組み

### ヨット
- 470級ヨットの外観を再現しています。
- 船体は台座にロール軸（前後方向）のヒンジでつながるだけの土台で、実際には前進しません。
- 船体の重心はセンターボード相当の低い位置に置き、アームの重心の高さによる倒れやすさを緩和しています。

### 傾ける力（風）
- 帆の受風中心に、風の強さ `w(t)` に比例した横向きの力をかけます。
- 傾くほど帆が風を逃がすので、力を `cos²θ` で弱めています。

```
τ_wind = τ_max · w(t) · cos²θ        (τ_max = 3.0 Nm)
```

### ロボット
- SO-101 を風上側の舷に固定し、先端に重り（0.35kg）を持たせています。
- AI の出力は 0 = 畳む、1 = 風上へいっぱいに乗り出すの目標値1つだけで、各関節は2つの姿勢の間を補間して動きます。
- ハイク量の変化速度には上限（2.0 /秒）があります。

### AI（強化学習）
| 項目 | 内容 |
|---|---|
| 観測 | 傾き角、角速度、現在のハイク量、現在の風の強さ、過去2秒分の風（0.25秒おき8点） |
| 行動 | ハイク量の目標値 |
| 報酬 | 傾きが小さいほど高い。アームを急に動かすと少し減点。転覆（±70°）で大きく減点して終了 |
| 学習 | PPO、60万ステップ、8環境並列 |

風の履歴を観測に入れているので、突風のリズムを覚えて**傾く前に乗り出す（先読み）**ことができます。

### 風のデータ
- **学習用**（200本）: 平均風速、突風の周期・強さ・立ち上がりの速さ、急な風の抜けをランダムに変えた60秒の時系列
- **テスト用**
  - `storm`: 強風・短い周期の突風
  - `irregular`: 不規則なリズム
  - `lull`: 強風からの急な風の抜け

CSV（`t,wind`）なので、実測の風速データに差し替えることもできます。

### 前進とゴール（見栄え用）
実際には進まない代わりに、傾きから速度を計算して進んだ距離を求めています。学習の報酬には使っていません。

- 平らなときの最高速度 4.0 m/s、加速 0.5 m/s²、減速 1.2 m/s²
- 傾き30°で速度ゼロ
- 30m 進んだらゴール

## 結果

同じ風（学習用の43番目のデータ）で、学習の段階ごとに比較した結果です。

| モデル | 平均傾き | 最大傾き | 30mゴール |
|---|---|---|---|
| 制御なし | 22.9° | — | 転覆 |
| 学習初期（2万ステップ） | 24.5° | 67° | 54.3秒 |
| 学習中期（3.5万ステップ） | 13.8° | 32° | 13.5秒 |
| 適合後（60万ステップ） | 1.3° | 6° | 11.5秒 |

学習に使っていない未知の風でも、適合後のモデルは転覆せずにゴールしました。

| 未知の風 | 30mゴール |
|---|---|
| 不規則なリズム | 11.5秒 |
| 強風からの急な風の抜け | 12.1秒 |
| 強風・短い周期の突風 | 11.8秒 |

全チェックポイントの評価は `evaluate.py` で確認できます。

## 使い方

[uv](https://docs.astral.sh/uv/) が必要です。

```bash
uv sync

# 風のデータを作る（data/wind/ に同梱済み）
uv run python -c "from yacht import wind; wind.make_dataset()"

# 学習（チェックポイントは checkpoints/ に保存）
uv run python train.py --steps 600000

# 全チェックポイントを評価
uv run python evaluate.py

# 動画を作る（video/yacht_balance.mp4）
uv run python render_video.py --early ppo_20000_steps --mid ppo_35000_steps --final ppo_final
```

GPU は使用していません。画面を出さずに描画する場合は、環境に合わせて `MUJOCO_GL`（`egl` / `osmesa` / `glfw`）を設定してください。

## ファイル構成

```
yacht/
  model.py   ヨットとアームの MuJoCo モデルを組み立てる
  env.py     Gymnasium 環境（風の力、ハイク量、報酬、速度とゴールの計算）
  wind.py    風のデータの生成と読み込み
train.py         PPO の学習
evaluate.py      チェックポイントの評価
render_video.py  提出用動画の作成
data/wind/       風のデータ（train/ と test/）
checkpoints/     動画で使った学習済みモデル
assets/          SO-101 モデルとフォント
docs/assignment.md  最終課題の概要メモ
```
