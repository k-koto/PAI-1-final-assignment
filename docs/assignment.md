# 最終課題の概要メモ

『Physical AI講座 2026 応用編1』の最終課題は、AIを活用してロボットに自由なタスクを実行させる課題です。講義資料の最新版（10月19日改訂版）では、概要は以下のとおりです。

課題内容
課題名
AIロボティクスによる創造的タスクの実現

目的
AI技術を使って、ロボットが実行するタスクを設計・実装し、創造性や技術力を示します。

必須条件
ロボットに何らかのタスクを実行させる
AIを何らかの形で使用する
AIによる推論のみでも可
学習まで行う必要はありません
タスクの内容は自由に設定可能
ROS、Gazebo、Genesisなどのシミュレータを想定していますが、他のツールや実機の使用も可能です
提出物
動画

ロボットがタスクを実行している様子
1分～3分以内
2倍速再生も可。ただし、倍速を使用した場合は動画内または概要欄に明記
使用したコード一式

GitHubリポジトリのURLを提出
リポジトリはpublic設定にする必要があります
簡単なレポート

PDF形式
課題の概要・目的
工夫した点などを記載
提出方法
提出は次の2つを両方行います。

1. OmniCampus
レポートPDF
GitHubリポジトリURL
2. YouTube
動画をYouTubeにアップロード
動画URLをOmniCampusの指定フォームに提出
公開設定は限定公開以上が必須
全体公開は推奨され、優秀作品の選出時に加点対象となる場合があります
採点が完了するまでは、動画を削除したり非公開に変更したりしないでください
また、レポート・コード・動画には、氏名、所属、メールアドレスなどの個人情報を記載・映し込まないよう注意してください。

スケジュール（予定）
提出開始：2026年10月19日
提出締切：2026年11月2日（月）AM10:00
結果発表：2026年11月下旬以降予定
評価
資料上の合格ラインは、ロボットがタスクを実行している動画と、必要な提出物を提出することです。

加点要素として、次の点が挙げられています。

創造性：独自性のあるアイデアやアプローチ
技術力：高度な技術や複雑な制御
実用性：現実世界での応用可能性
表現力：動画の構成や説明のわかりやすさ
剽窃、サンプルの丸写し、関係のないファイルの提出などは、修了判定の対象外となる可能性があります。

まずは、例えば「画像認識で対象物を判別し、ロボットが運搬・分類する」「音声指示に応じてロボットが動作する」といったように、AIの役割とロボットのタスクが明確なテーマを決めると進めやすいです。
